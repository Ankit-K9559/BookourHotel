# BookOurHotels

**BookOurHotels** is a web application designed to connect unorganised homestays with travelers, making local accommodations easily discoverable and bookable.

## ✨ Features

* **Homestay Discovery:** Explore unorganised local homestays easily in one place.
* **Modern UI:** Responsive, fast, and interactive user interface built with TypeScript and Vite.
* **Seamless Booking:** Streamlined process for guests to find and secure homestay bookings.

---

## 🛠️ Tech Stack

* **Frontend:** TypeScript, HTML5, CSS3
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Package Manager / Runtime:** [Bun](https://bun.sh/)

## 🚀 Getting Started

Follow these instructions to get a local copy up and running.

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed on your machine.

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/Ankit-K9559/BookourHotel.git
cd BookourHotel

```


2. **Install dependencies**
```bash
bun install

```


3. **Set up environment variables**
Copy the example environment file and update your variables:
```bash
cp .env.example .env

```


4. **Run the development server**
```bash
bun run dev

```


5. **Build for production**
```bash
bun run build

```
